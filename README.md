# Català amb la Berta 1 📚📱

**Català amb la Berta 1** és una aplicació web interactiva, accessible i adaptada (especialment dissenyada per a alumnes amb dificultats d'aprenentatge com TDAH, DDA o dislèxia) per practicar la sintaxi i la gramàtica catalana de manera visual, amena i dinàmica.

---

## 🌟 Característiques principals

* **Disseny Mobile-First & Accessible**:
  * Interfície optimitzada per a smartphones amb barra de navegació inferior (*Bottom Nav Bar*) fàcil d'utilitzar amb els polzes.
  * Targetes i botons tàctils mida XXL (àrea de toc mínima de 52px) per evitar clics d'error.
  * Selector de font adaptada per a dislèxia (*OpenDyslexic*) i botó per canviar la mida de la lletra.
  * Paleta de colors pastel de clar contrast per reduir la fatiga visual i millorar l'enfocament.
* **Contingut Pedagògic Adaptat**:
  * **Sintagma Nominal (SN)**: Estructura `(Determinant) + Nom + (Complements)` (Adjectiu, Sintagma Preposicional, Frase).
  * **L'Apostrofació de l'Article Femení**: Regla clara sobre quan s'apostrofa *"LA"* i l'excepció de la *i/u* àtona (ex. *La universitat*, *La indústria* vs *L'illa*).
  * **Anàlisi Sintàctica Pas a Pas**: Pauta numèrica de 4 passos per identificar el verb, el nombre (singular/plural), el subjecte i detectar si és el·líptic.
  * **Sintagma Verbal (SV) i Frases Impersonals**: Reconeixement de frases impersonals (meteorològiques, *hi ha / hi havia*, *es + verb*).
* **Exercicis i Test Dinàmics**:
  * Banc de dades d'exercicis aleatoris que es barregen en cada sessió o en clicar **"Nous"**.
  * Correcció immediata i retroalimentació explicativa pas a pas amb efectes visuals (*confetti*).

---

## 🛠️ Tecnologies utilitzades

* **HTML5** (Estructura semàntica)
* **Tailwind CSS** (Disseny d'estils i adaptabilitat mòbil)
* **JavaScript (ES6+)** (Lògica interactiva, generació aleatòria d'exercicis i gestió de l'estat)
* **Lucide Icons** (Iconografia visual i intuïtiva)
* **Canvas Confetti** (Retroalimentació positiva immediata)

## 🚀 Com executar el projecte localment

1. Clona aquest repositori:
   ```bash
   git clone https://github.com/el-teu-usuari/catala-amb-la-berta-1.git
   ```
2. Accedeix a la carpeta del projecte:
   ```bash
   cd catala-amb-la-berta-1
   ```
3. Obre el fitxer `index.html` a qualsevol navegador web (o utilitza una extensió com *Live Server* a VS Code).

---

## 🌐 Publicació a GitHub Pages

Per publicar l'aplicació gratuïtament a internet mitjançant GitHub Pages:

1. Subiu el fitxer `index.html` i `README.md` a la branca principal (`main` o `master`) del vostre repositori de GitHub.
2. A GitHub, aneu a la secció **Settings** del repositori.
3. Al menú lateral esquerre, seleccioneu **Pages**.
4. A **Build and deployment > Branch**, seleccioneu `main` (o `master`) i la carpeta `/ (root)`.
5. Feu clic a **Save**. En un parell de minuts, GitHub us proporcionarà l'enllaç públic de l'aplicació.
